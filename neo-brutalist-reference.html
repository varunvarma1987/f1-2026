Anti-AI
Rules

02 / GUARDRAILS

The clichés the skill deliberately avoids, so output doesn't drift toward generic polish.

No emojisNever used anywhere in the design.
No gradientsSolid colors with hard edges only.
No purple/violetBold primaries or neons instead.
No hero badgesBrutalism doesn't whisper.
No glass morphismToo refined, too polished.
No soft shadowsHard, offset shadows only.
No thin borders4px minimum, always.
No subtle hoversBold, obvious transformations.
No muted pastelsSaturated, loud colors.
No smooth transitionsInstant or stepped changes.

05 / BUTTONS, CARDS, FORMS

Buttons — hard shadow, offset only, shadow collapses on press.

Cards — three treatments: hard-shadow card, flat colored card, stacked-offset card.

01 / SHADOW CARD

STANDARD

Hard offset shadow, 4px border, no blur. The default container across the system.

02 / FLAT COLOR

FEATURE

Border only, no shadow — reserved for a single loud color block per section.

03 / STACKED

OFFSET

A second flat block sits behind at a fixed offset instead of a blurred shadow.

Form elements — thick borders, mono labels, shadow appears on focus.
